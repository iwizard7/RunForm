Your running data,
coached by a local AI

RunForm imports your workouts, stores them in a local SQLite database and turns raw numbers into coaching insights — reviews, plans, chats and forecasts. Everything runs on your Mac: no cloud, no accounts, no data leaves your machine.

⬇︎ Install on macOS View on GitHub
Next.js 16 React 19 SQLite Ollama macOS RU / EN
Terminal — one command 
# installs Node 20, dependencies, Ollama + model, builds & opens the app
curl -fsSL https://raw.githubusercontent.com/iwizard7/RunForm/main/scripts/bootstrap-mac.sh -o /tmp/runform-bootstrap.sh && bash /tmp/runform-bootstrap.sh

Requires macOS and Homebrew. First run downloads the ~2.6 GB AI model — later launches take seconds.

Everything a running log should do

Import, analyze, plan — with an AI coach that actually knows your history.

📊

Deep workout analysis

HR zones, MET-load, efficiency, cadence, stride length, weather stress and recovery trend — computed locally from every imported workout.

🤖

AI coach on Ollama

Streamed reviews, next-session plans, weekly digests and a chat that knows your records. Pick any installed model in Settings.

📸

Screenshot import

Photo of a Strava or Garmin screen? A local vision model turns it into a structured workout entry — no typing.

🗺️

GPS splits & track map

Per-kilometre pace and heart rate, offline SVG route coloured by pace, plus an AI fatigue analysis of the run.

📅

Calendar & plans

A month grid with daily load, weekly AI microcycles with real dates, and training plans you can save and track.

🚩

Health red flags

Personal bests, HRV readiness, overtraining markers and a GO / CAUTION / REST verdict before hard sessions.

A clear picture of every run

Dark, focused UI built for quick glances after a workout.

🔒 Private by design

Workouts live in a local SQLite file. The AI runs through a local Ollama instance. There is no backend, no telemetry and no account — RunForm works fully offline.

Open source

RunForm is free and open source. Issues and pull requests are welcome.

📦 Clone & run

Prefer manual setup? git clone, npm ci, ./scripts/start-workout-app.sh — full instructions in the README.

🧪 CI-verified

Every push runs lint, 80+ logic tests and a production build on GitHub Actions, so main always boots.
